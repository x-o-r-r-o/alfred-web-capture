# Web Capture

Turn the current page or a URL into Markdown, a full-page screenshot, a code image, or a YouTube transcript.

> **Status:** planned — not yet functional. See [PLAN.md](PLAN.md).

## Usage

Turn the current page or a URL into Markdown, a full-page screenshot, a code image, or a YouTube transcript via the `tomd` keyword.

![Web Capture results in Alfred](images/tomd.png)

* <kbd>↩</kbd> Primary action.
* <kbd>⌘</kbd><kbd>↩</kbd> Secondary action.
* <kbd>⌘</kbd><kbd>Y</kbd> Quick Look.

Every keyword can be changed in the Workflow’s Configuration.

## Development

```bash
./build.sh   # -> dist/alfred-web-capture-<version>.alfredworkflow
```
